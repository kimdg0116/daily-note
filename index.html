홈 화면 위젯

오늘·내일 할 일을 아이폰 홈 화면에 · 눌러서 설치 방법
  1. App Store 에서 Scriptable 설치
  2. 아래 설치 코드 복사 → Scriptable 오른쪽 위 + → 붙여넣기 → 맨 위 제목을 데일리 위젯 으로 바꾸고 Done
  3. 목록의 데일리 위젯을 눌러 실행 → 연결 코드(위 폰 연동과 같은 코드) 입력 → 미리보기로 확인
  4. 홈 화면 빈 곳을 길게 누름 → 편집 → 위젯 추가 → Scriptable → 소형·중형·대형 중 골라 추가
  5. 추가한 위젯을 길게 눌러 위젯 편집 → Script: 데일리 위젯
  6. 위젯 색 맞추기를 누르면 위젯이 지금 테마 색으로 바뀝니다 (테마 색을 바꿀 때마다 한 번)

    

    
소형 = 오늘 · 중형 = 오늘 | 내일 · 대형 = 오늘 + 내일. 앱에서 체크하면 위젯은 iOS 가 다시 그릴 때(보통 몇 분~15분 안) 바뀝니다. 위젯을 누르면 iOS 가 사파리로 여니, 앱은 홈 화면 아이콘으로 여세요. Scriptable 목록의 daily-note-widget-core 는 위젯 본체라 지우지 마세요.
