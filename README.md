# 데일리 노트 (맥 앱 + 폰 앱)

옵시디언 데일리 노트(`04 Life/Planner/Daily/YYYY-MM-DD(요일).md`)를 앱 화면으로 쓴다. 쓰는 대로(0.5초 뒤) 그 노트에 저장되고, 옵시디언에서 고쳐도 같은 노트다.

- 실행: `데일리 노트.app` 더블클릭 (Dock 에 끌어다 두기). 한 번만 뜨고 Dock 을 다시 누르면 있던 창이 앞으로 온다. 서버가 없으면 앱이 띄운다.
  - 앱만 데스크톱 등으로 옮겨 둬도 된다 (서버는 이 폴더 것을 쓴다). 앱이 없거나 `main.swift` 를 고쳤으면 `./make_app.sh`.
  - `server.py` 를 고쳤으면 서버를 다시 켜야 한다 (명언 정리 중이 아닐 때 서버를 끄고 앱에서 ⌘R - 서버가 없으면 앱이 다시 띄운다). 서버만은 `python3 server.py` (127.0.0.1:8749, 로그 `/tmp/daily-note.log`).
- 날짜를 고르면 그 날 노트를 연다. 노트가 없는 날은 쓰기 시작할 때 데일리 템플릿 그대로 만든다 (Templater 대신 앱이 날짜 링크, 어제 Tomorrow's Tasks, 오늘의 명언을 채운다).
- 칸 대부분이 frontmatter 값(meta-bind)이라 바꾼 키만 고친다. 할 일·공부·Journal 은 본문 그 자리만 고친다.
- 날짜 버튼을 누르면 달력이 뜨고, 노트가 있는 날에 점이 찍힌다.
- 다가오는 일정: 옵시디언 `04 Life/Planner/일정.md` 의 `- [ ] YYYY-MM-DD 이름` 줄을 날짜 카드 아래에 날짜순으로, 보고 있는 날 기준 D-day 와 함께 보인다 (7일 안은 연하게, 그날은 진하게, 지난 것은 빨갛게). 앱에서는 체크(끝낸 날 `✅ 오늘` 을 붙인다, 바탕화면 위젯이 그날은 체크된 채로 보인다)·추가하고, 줄을 옆으로 밀면(폰 스와이프, 맥 트랙패드) 나오는 삭제로 그 줄을 지운다. 일정을 누르면 그 자리에서 날짜·이름을 고친다 (체크·넣은 날·끝낸 날은 그대로). 다른 줄은 건드리지 않는다.
  - 날짜 없이 `- [ ] 이름 ➕ 넣은 날` 이면 기한 없는 일정: 카드 맨 위 "가능한 빨리" 에 넣은 지 며칠째인지 (7일 안 연하게, 14일 안 주황, 그 뒤 빨갛게). 달력의 "기한 없음" 으로 넣는다.
  - 폰: 맥이 일정 목록을 우체통 meta(plans)로 보내고, 폰에서 바꾼 것은 `op:'plan'` 으로 모였다가 맥이 일정 노트에 쓴다 (`po`·`pdone`).
- 운동 기록·Journal·마음 기록 칸은 편집기(CodeMirror, `cm.js`)라 옵시디언처럼 `**굵게**`(⌘B)의 기호는 숨기고(커서가 그 안에 오면 보임) 줄 맨 앞 `- ` 는 점으로 보여 준다. 노트에는 마크다운 그대로 저장된다. `cm.js` 는 `build_cm.sh` 로 만든 묶음이라 평소엔 손대지 않는다.
- 마음 기록 칸은 템플릿을 읽어서 만든다 (템플릿의 `---` 로 나뉜 묶음마다 카드 하나: 하루 돌아보기 · 힘든 날에만 · 이번 주 모아 보기). 템플릿에 질문을 더하면 앱에도 생긴다. 토글 줄이 없는 칸은 늘 펼쳐 둔다.
- 하루 마무리: 몸(`body`)·마음(`mood`) 1~5, 수면(`sleep`), 술(`alcohol`), 오늘의 한 줄.
- 이번 주 모아 보기: 그 주(일~토) 노트의 `법칙_기록` 을 모아 보여 주고, 누르면 그 날로 간다. 맥·폰 모두 `/api/day` 로 읽는다.
- 템플릿에서 빠진 칸에 쓴 답은 그 노트 본문의 양식으로 읽어 '이전 칸' 카드로 보인다 (`mind_old`). 파일과 옵시디언은 그대로다. 8~9월의 콜아웃 양식 노트는 읽지 않는다.
- 템플릿 위쪽(할 일·운동·하루 마무리)이나 Templater 코드를 바꾸면 `server.py` 도 같이 본다 (모르는 Templater 코드가 있으면 노트를 만들지 않고 알린다).
- 명언: 새 노트를 만들 때, 그리고 오늘 노트에 정리 안 된 명언이 있으면 `claude -p "/명언 <날짜>"` 를 알아서 돌린다. 끝나면 번역·판정·저자 카드가 뜨고, 저자 노트는 옵시디언 `04 Life/명언/저자/` 에 있다.
- 명언 모음(상단 바 따옴표 아이콘, 명언 카드의 '명언 모음'): 옵시디언 `📜 명언 모음` 과 같은 기준이다. 명언 카드의 **모으기**(`quote_체크`)를 켠 명언이 모이고(토글이 생기기 전 2026-08-08 까지 노트는 전부), **별**을 누르면 위 '마음이 가는 명언'으로 올라간다. 별은 `📜 명언 모음` 노트의 `favorites` 에 쓴다 (데일리 노트는 안 건드림). 예전 명언 형식(제목 줄에 명언, 콜아웃 없는 번역)도 읽는다.

## READING (읽을 글)
- 맨 위 제목(DAILY)을 누르면 바로 아래에 화면 목록이 붙어 나온다 (도시메트리 캘린더의 제목 메뉴와 같은 방식). READING 을 고르면 제목이 READING 으로 바뀐다. 날짜 단추(전날 · 날짜 · 다음 날 · 오늘)는 DAILY 화면에서만 제목 아래 한 줄로.
- 목록 기준은 옵시디언 Home 「읽어야 할 글」(볼트 `90 System/scripts/read-queue.js`)과 같다: `type` 이 note·literature, 폴더가 일(01 Work · 의학물리) · 클리핑(메르의 블로그 · Valley AI 피드 정리·시황 · 04 Life/읽을거리) · 개념(03 Economy/개념 · 04 Life/시사 교양, 또는 `origin: question`), `read_on` 이 없거나 오늘. 정리일 최근 순.
- 읽음(목록의 동그라미, 또는 본문 아래 단추·Cmd+Enter): 그 노트 frontmatter 의 `read_on`(오늘)·`memo`(메모, 있을 때만. 여러 줄이면 `|-` 블록) 두 키와, 그날 데일리 노트의 콜아웃 둘만 고친다. `> [!abstract]- 오늘 읽은 글`(「오늘 작성·수정한 노트」 바로 아래)엔 `> - [[제목]]` 링크만, 그 바로 아래 `> [!abstract]- 읽은 글 메모`엔 메모 문장만 `> - 문장` 으로 (어느 글 메모인지는 노트 `memo` 속성과 READING 「메모」에). 메모 칸은 Enter 가 줄 바꿈 (빈 줄·줄마다 겹친 공백은 뺀다, 3000자까지). 오늘 노트가 없으면 템플릿으로 만든다. 본문에서 누르면 다음 글로 간다.
- 되돌리기: 오늘 읽은 글의 체크를 다시 누르거나 본문의 읽음 취소. `read_on` 은 빈 값(Home 체크를 풀 때와 같다), `memo` 와 링크 줄·메모 줄은 지운다 (마지막 줄이면 콜아웃도). 메모는 읽은 뒤에도 고칠 수 있다.
- DAILY 화면 「읽은 글 메모」 칸: 그날 노트의 「읽은 글 메모」 콜아웃(`SECS['memos']`, 공부 칸처럼 '> ' 를 떼고 붙인다)을 그대로 편집한다. READING 에서 메모를 고치면 고치기 전 메모 줄이 그대로 있을 때만 바꾸고, 데일리에서 다듬어 없으면 새로 생긴 줄만 덧붙인다 (`memo_set`, 다듬은 문장은 덮거나 지우지 않는다). 메모가 없는 날은 칸이 없다.
- 「오늘 읽음 N」 단추: 누르면 오늘 읽은 글만 (다시 누르면 전체로). 전체 목록 맨 아래 「오늘 읽은 글」과 같은 줄.
- 「메모」 칩: 메모를 남긴 글을 지난 것까지 읽은 날 최근 순으로 모아 본다 (`read_items` 가 memo 있는 글은 날이 지나도 목록에 넣는다). 지난날 읽은 글은 읽음 단추를 숨기고 메모만 고친다 (`day` = 그 읽은 날로 보내 `read_on` 은 그대로, 그날 데일리 노트가 있으면 그 줄을 고치고 없으면 새로 만들지 않는다). 메모를 다 지우면 빠진다.
- 아이패드(`any-pointer:coarse` + 700x600 이상): 같은 px 이면 폰보다 멀리 두고 보니 작아 보여 본문 글씨를 테마 크기의 1.2배, 목록·메모 칸도 조금 키운다. 맥·아이폰은 그대로.
- 본문: 맥 서버가 마크다운을 HTML 로 바꾼다 (markdown-it-py, 노트 속 HTML 은 글자로). 옵시디언 문법(콜아웃 · 접는 콜아웃 · `[[링크]]` · `![[그림]]` · `==형광펜==` · `%%주석%%` · 할 일 체크)을 따로 처리하고, Dataview 블록은 안내 한 줄로. 그림은 `90 System/첨부파일`(하위 폴더까지)에서 이름으로 찾는다.
- 모양: 볼트의 옵시디언 테마(`.obsidian/appearance.json` 의 cssTheme = Ink Paper)를 `/api/theme.css` 가 `.ink` 안에만 걸리게 바꿔서 그대로 쓴다. 테마를 고치면 앱도 같이 바뀐다. 앱이 라이트면 테마의 라이트, 다크면 다크.
- `[[링크]]` 는 읽을 글 목록에 있으면 앱에서, 없으면 옵시디언에서 연다. 웹 링크는 기본 브라우저로 (`/api/openurl`).
- 넓은 창(900 이상)은 왼쪽 목록 · 오른쪽 본문, 좁으면 본문이 목록 위로 밀려 들어오고 뒤로 가면 보던 자리 그대로.
- 폰: 맥이 우체통으로 목록(바뀔 때만)과 테마를 보내고, 본문은 폰이 달라는 것만 보낸다 (안 읽은 글 위에서 24개 + 연 글, 한 번에 압축 45KB 까지, 우체통 본문 상자 90KB). 폰은 받은 본문을 IndexedDB `rdocs` 에 두고 목록에서 빠지면 지운다. 노트가 바뀌면(v = mtime) 다시 받는다. 없는 본문을 열면 그 글부터 달라고 하고 2분 동안 3초마다 받는다. 폰에서 누른 읽음·메모는 `rmark` 로 우체통 편지함(rob)에 → 맥이 누른 날 기준으로 노트에 쓰고 rdone 으로 알린다. 그때까지는 폰 목록에 얹어 둔다. 볼트 그림(첨부파일)은 폰이 받아 둔 본문(위 24개 + 연 글)에 든 것을 `iwant` 로 달라고 하면, 맥이 sips 로 폭 1100 JPEG(투명 PNG 는 PNG)로 줄여 우체통 Script Cache 에 6시간 넣고(Script Properties 500KB 와 따로, 권한 더 필요 없음, 한 번에 2MB), 폰이 `img` 로 가져가 IndexedDB `rimgs` 에 둔다. 남은 본문이 안 쓰는 그림은 지운다. 아직 없는 그림은 "그림 받는 중" 줄로 있다가 들어오면 그 자리에 바뀐다. 웹 그림은 그대로 보인다.

## 폰 앱 · 연동
- 폰 앱 = 같은 `index.html` 을 GitHub Pages(`kimdg0116/daily-note`)로 띄운 홈 화면 앱. https 로 열리면 폰 모드가 된다 (manifest·sw.js·version.json, 앱 버전은 `APP_VERSION`·`sw.js`·`version.json` 세 곳 같이).
- 연동은 토플 단어 앱처럼 Apps Script 우체통(`sync/Code.js`, 프로젝트 "데일리 노트 동기화"). 우체통은 **전달만** 한다 (Script Properties 만 써서 권한이 필요 없다).
  - 노트 원본은 맥 볼트, 사본은 폰 안(IndexedDB)에 전부. 기한·용량 걱정 없음.
  - 폰을 처음 연결하면 폰이 '다시 받기'(want)를 걸고, 맥이 모든 노트를 날짜순으로 묶음(80개·250KB)씩 보낸다 (폰이 앞 묶음을 받은 뒤 다음 묶음).
  - 그 뒤로 맥은 30초마다(맥에서 저장하면 바로) 바뀐 노트만 상자에 넣고, 폰이 받아 간다. 상자가 300KB 를 넘으면 오래된 것부터 버리고, 그보다 오래 안 연 폰은 처음부터 다시 받는다.
  - 폰에서 고친 칸은 받은 편지함에 모였다가 맥이 볼트에 쓴다. 폰에서 단 별은 그 날짜 수정에 `_fav` 키로 실려 와 맥이 명언 모음 노트에 쓴다. 명언 모음 목록은 맥이 바뀔 때마다 우체통 meta(quotes)로 보낸다. 맥이 꺼져 있으면 편지함에 남았다가 맥 서버가 켜질 때 들어간다.
- 같은 칸을 폰과 맥에서 둘 다 고쳤으면 나중에 고친 쪽이 이긴다 (`server.py` `pick`).
- 연결 코드는 `sync/Secret.js` (git 제외). 맥 앱 설정 > 폰 연동에 보이고, 폰 앱 설정에 넣는다.
- 연동 서버 반영: `cd sync && ~/Code/apps/dosimetrist-calendar-server/tools/node_modules/.bin/clasp push -f && …/clasp redeploy AKfycbwAzbhrtPtjrd8KVQuFTFXfgLmzY4Cgsk-DZlF2ur3b6a7hU_LMQOaKddSt-0O9mOIP -d "설명"`
- 맥에서 폰 화면 시험: `node sync/test_sync.mjs --serve`(가짜 우체통 8751) + `http://127.0.0.1:8749/?phone`. localhost 의 폰 모드는 늘 가짜 우체통으로만 간다 (진짜 노트에 시험 글이 섞이지 않게).

## 아이폰 위젯 (오늘·내일 할 일)
- `widget.js` = Scriptable 위젯 본체 (Pages 에 올라감). 폰에는 앱 설정 > 홈 화면 위젯의 짧은 설치 코드만 붙여넣고, 그 코드가 매번 본체를 받아 실행한다 → 본체를 고쳐 push 하면 위젯이 바뀐다.
- 소형 = 오늘 · 중형 = 오늘 | 내일 · 대형 = 오늘 + 내일. 보기만 (체크는 앱에서). 오늘 노트가 아직 없으면 어제 노트의 내일 할 일.
- 데이터는 우체통 `op:'widget'` (읽기만, 폰 수정 ob 를 얹음 → 맥이 꺼져 있어도 폰 앱에서 체크한 게 보인다). 다시 그리는 때는 iOS 가 정한다.
- 색은 도시메트리 캘린더 widget.js 와 같은 16색(PALETTES). 앱 '위젯 색 맞추기' → `scriptable:///run/daily-note-widget-core?color=<id>`.
- 미리보기: Scriptable 흉내 페이지에 widget.js 를 그대로 넣어 돌려 본다 (실기기 확인은 폰에서).

확인: `python3 test_note.py` (템플릿 렌더·칸 읽고 쓰기·명언 칸·마음 기록 양식·폰 수정 고르기·읽을 글 줄과 본문 HTML), `node sync/test_sync.mjs` (우체통, 읽을 글 본문 상자·요청·읽음 편지함·그림 캐시 포함)
시험: `PORT=8750 VAULT=<사본 볼트> CLAUDE=<가짜 claude> [SYNC_URL=http://127.0.0.1:8751] python3 server.py` 로 실제 볼트를 건드리지 않고 돌려 볼 수 있다.
